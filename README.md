# linkgraph (archived)

This repo is archived. The code lives in [agentic-rag/packages/linkgraph](https://github.com/trentmilam/agentic-rag/tree/main/packages/linkgraph), and that is where new work happens.

linkgraph builds a relationship graph across documents: which RFC obsoletes which, which erratum
corrects what, and which entities keep turning up together. It is built from a real
21,830-mention extraction.

It moved because agentic-rag uses it to resolve RFC supersession.

Its commit history up to the move went with it.
